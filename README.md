# 🌐 Web Development Training Repository

Welcome to the comprehensive Web Development training repository! This project is structured across multiple branches, each focusing on a specific aspect of modern web development, from HTML basics to advanced JavaScript concepts.

## 📂 Repository Structure

The repository is organized into three main modules: HTML, CSS, and JavaScript. Each module is further divided into assignments located in separate branches.

## 🚀 How to Use

To explore a specific assignment or topic, switch to the corresponding branch using the following command:

```bash
git checkout <branch-name>
```

For example, to view the Flexbox assignment:

```bash
git checkout flex
```

To see the list of all available branches:

```bash
git branch -a
```

## 📝 Assignment Overviews

### HTML Module
- **Intro & 20 Tasks**: Start here to get comfortable with HTML syntax.
- **Assignment 3**: Build a structured Resume using semantic HTML.
- **Assignment 4**: Create a robust navigation system using iFrames and links.

### CSS Module
- **Assignment 5**: Apply basic styles to HTML pages.
- **Flexbox (Assignment 6)**: Learn to create flexible and responsive layouts.
- **Box Model (Assignment 7)**: Master spacing, borders, and dimensions.
- **Advanced CSS (Assignment 8)**: Add life with animations and complex selectors.
- **Responsive Design (Assignment 9)**: Ensure your sites look great on all devices.
- **Bootstrap (Assignment 10)**: Rapidly prototype with the Bootstrap framework.

### JavaScript Module
- **Intro (JS Assignment 1)**: Write your first scripts (e.g., Personalized Login Greeting).
- **Operators (JS Assignment 2)**: Perform calculations and logic checks.
- **Features (JS Assignment 3)**: Utilize modern JavaScript syntax.
- **Classes (JS Assignment 4)**: Structure code with classes and objects.
- **Functions (JS Assignment 5)**: Modularize code with reusable functions.
