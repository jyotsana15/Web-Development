Responsive CSS Cheat Sheet

Filters

CSS filters are used to apply graphical effects like blur or color shifting to an element.

filter: grayscale(100%);

Media Queries

Media queries are used to apply different styles for different media types/devices.

@media (max-width: 600px) { ... }

Responsive Design

Responsive web design makes your web page look good on all devices.

Typography

Responsive typography adjusts font sizes based on the viewport.

font-size: clamp(1rem, 2vw, 1.5rem);
